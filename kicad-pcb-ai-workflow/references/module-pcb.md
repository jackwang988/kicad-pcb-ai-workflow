# PCB Stack-up, Placement, Routing and Copper

1. **Stack-up and rules before placement:** Obtain current factory capabilities, laminate/material and copper parameters; define trace/clearance, via drill/diameter, annular ring, edge clearance, differential impedance, net classes, voltage separation and board outline. Write through the accepted EDA backend and read effective KiCad rules back; a JSON policy alone does not prove a rule is active.
2. **G3 placement:** Constrain board mechanics, connectors, mounting holes, antenna and keepouts first, then power loops, oscillator/decoupling, sensitive analog and high-speed groups, then ordinary placement. Use stage-specific node-03 knowledge cards. `placement_review.py` is a read-only assessor, not an autorouter or auto-placer. Verify actual pad geometry, UUIDs, return paths and routing channels.
3. **Routing in seven steps:** Check rules, classify *every* net, plan critical nets, execute ordinary signals in batches, handle power/ground, then **first fill real GND zones**, inspect island/pad-to-plane and cross-layer return topology, add **only required and approved** GND stitching vias, **refill all modified GND zones and save/reload**, run the `pcb.ground_plane_audit` gate and only then run full native KiCad DRC. A pre-fill GND airwire is expected, not G4 failure. See [mandatory GND/DRC order](gnd-before-drc.md). Unknown nets must not silently become ordinary signals. Offline A* search is a route proposal, not applied copper; Freerouting output is not proof of a successful KiCad import. Never assume that all ground connections are satisfied solely by final zone fill.
4. **G4:** Inspect actual copper layers, trace and via geometry, reference planes, return loops, RF/antenna clearance, differential skew and manufacturing constraints. Reuse verified cards without skipping project-specific evidence or engineer approval.

Konnect MCP is the sole active writer; Python is for algorithms/verification. If a necessary operation lacks a compatible accepted tool, block it rather than downgrade engineering rules or secretly use legacy `pcbnew` writes. Use [engineering rules](engineering-rules.md), [routing policy](constraint-routing.md), [placement quality](placement-quality.md) and [latest workflow](latest-complete-workflow.md).

## Rules-first functional-module layout planning (R10 preview)

Run `pcb.layout_preflight` after approved stack-up/fabricator rules are applied to the synchronized KiCad PCB and before any automated G3 move. It reuses the existing `design_intent_audit.py` native effective-NetClass check and verifies actual Board Setup minima; then `pcb.layout_plan` computes bounded intra-module locations and small global module translations while preserving current connector/mechanical anchors. See [rules-first PCB module layout](pcb-module-layout.md). These tasks never edit EDA: apply through Konnect only, then run saved footprint-position readback and the existing **G3 placement-only** gate (`pcb.placement_pre`, `--phase pre_route`). **No full-board KiCad DRC or zero-unconnected requirement at G3**; full DRC belongs to G4 after routing, power/GND and zone refill. Do not lower copper, via or courtyard rules to make a candidate fit.


## JLCPCB 2/4/6/8-layer factory constraints: explicit user consent before G3

After G2/F8, run `pcb.fab_preview` to propose a source-dated **conservative** JLCPCB rigid FR-4 profile. Present board layer count, nominal thickness, finished copper, minimum line width/spacing, via drill/diameter, annular ring, hole-to-hole, edge and courtyard clearance, and unresolved exact impedance stackup/surface finish. Published factory minima are **not** the Skill's design defaults. **Stop and get the actual user's explicit confirmation**; do not auto-confirm. Only then `pcb.fab_confirm --apply` creates immutable approval and fab-rule sidecars, without editing KiCad. Apply actual KiCad Board Setup/NetClasses via the authorized Konnect writer, read back effective physical rules/stackup, and run `pcb.layout_preflight` → `pcb.layout_plan` using `fab_approval` and `fab_rules` from the approval. Source, layer, profile or thickness drift requires new user review. See [JLCPCB confirmation](jlcpcb-fab-confirmation.md).

## Courtyard is not copper clearance (R10)

For G3 candidate placement, read the real F.CrtYd/B.CrtYd mechanical occupancy and the current effective KiCad custom `courtyard_clearance` rules. Supported source-bound top-side Courtyard polygons, explicit footprint Keepout zones, NPTH mounting holes and fixed anchors are screened before accepting a candidate. Do **not** substitute a footprint-center rectangle or global copper clearance for the real Courtyard. Source-declared pad-level proximity and decoupling must participate in placement, not merely post-layout review. Unknown hard geometry blocks. This is not a full native DRC evaluator; preserve saved-position readback and run the **G3 placement-only** review after accepted Konnect moves. Run native full-board DRC **only after routing and copper-zone refill at G4**. See [Courtyard-first details](pcb-courtyard-hard-rules.md).

## Fine-pitch pad escape and power trunk

Apply the user chart plus **0.254 mm only to required power trunk width**, not as an unconditional minimum for the short copper leaving every pad. Use a source-backed, exact-net/pad/layer/region, bounded-length neckdown only when necessary and only above the fab absolute minimum; verify its **own** current/thermal/drop budget and local KiCad custom-rule scope. The generic grid A* does **not** yet route variable-width segments or auto-apply these exceptions. Do not claim automatic control without an accepted Konnect operator and readback evidence. See [power neckdown contract](constraint-routing.md).

## Freerouting-first candidate for ordinary nets (not production-promoted)

See [the staged Freerouting-primary integration contract](freerouting-primary-routing.md). After whole-net classification and native rule/readback checks, prefer a **qualified external DSN/SES Freerouting candidate** for ordinary nets over custom LLM-operated global A*. Protect dedicated GND, RF, differential, high-current and timing-critical NetClasses using independently audited actual KiCad membership and `-inc`. Keep Konnect the sole KiCad writer, performing external candidate import/save/readback and critical native edits. Then refill GND zones and run independent full G4 DRC. The current external candidate is **not** a general accepted default: live all-board rule-fidelity and integration evidence remain pending. Freerouting's output alone must not be treated as routed manufacturing copper.

## Required seven-stage Freerouting path

The seven-stage procedure in [Freerouting seven-stage routing](freerouting-seven-stage.md) supersedes a blanket Konnect/global A* priority for normal nets: verify full inventory and factory/native rules first; place/lock special power, timing, differential and RF tracks; use approved Freerouting 2.5.0 for remaining **ordinary-only** connections (GND + protected NetClasses excluded); audit imported SES against a protected checkpoint; repair on a bounded new checkpoint; and refill GND with full native G4 DRC. This does not certify automated native import, save, KiCad GUI or production acceptance until separately tested. G3 remains placement-only.
