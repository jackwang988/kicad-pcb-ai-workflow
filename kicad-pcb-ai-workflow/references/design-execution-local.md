# 本地主流程修订与可执行优化方案

版本：R10.0-alpha.3-local.1，2026-11-14。本文是主流程范围与执行要求的本地修订，不是新自动布局/布线引擎的实现证明。原始脚本保留兼容；历史 CLI 六组/16节点、G5/G6 状态不能作为本主线待办或终点。与历史流程描述冲突时，以本文范围为准。

## 主线及交付状态

需求与环境 → 原厂资料与资源核对 → 原理图拓扑/绘制与G1/G2 → 真实PCB同步 → 工厂叠层与规则实际生效 → 实际布局与G3 → 节点10七步布线 → 最终评审G4 → DFM/DFT与隔离制造资料导出 → 资料完整性检查与移交。

删除主流程第六阶段。CAM/EQ、制造授权、样机测试、生产与ECO仅为外部扩展，只有用户另行提出才调用 module-lifecycle.md。既有制造导出安全门禁不能绕过。

`DESIGN_PACKAGE_READY_FOR_REVIEW` 是新增的交付摘要状态，含义仅为设计资料已准备好、待审核；不是既有脚本自动产生的状态，也不是生产放行。仅当实际设计检查完成、必要连接闭合、适用ERC/DRC及G1–G4证据有效、DFM/DFT适用项已审核、导出文件及清单哈希完整并与同一工程版本绑定时，才能在交付摘要中声明。缺失项列出并保持 BLOCKED 或 IN_PROGRESS；不伪造签核。原脚本 EXPORTED_NOT_RELEASED 等原始结果原样保留并单列，不能改写为生产批准。

## 规则：两级输入、独立验证

1. 工艺能力档案：板厂、来源日期、工艺编号、层序、材料、厚度、铜厚、最小线宽/铜间距、过孔外径与孔径、孔环、孔到孔、铜到板边、阻焊桥、槽孔与盲埋孔限制。缺参数不使用模板示例补齐。
2. 工程专项约束：逐网/网络类的电流与温升预算、目标/最小/最大线宽、差分几何、阻抗及容差、参考层、换层限制、长度/时延、隔离和安全要求。项目约束必须落在工厂可制造域内；不满足则提出工艺或设计变更，不能自动放宽。
3. 生成规则映射清单：每项要求 → 原生字段/custom rule → 适用对象 → 写入工具 → 回读方法 → 验证证据。不存在写入能力的项标 unsupported，阻断相关操作。
4. 在隔离候选中写入 .kicad_pro/.kicad_dru 与实际叠层；保存重载，用原生规则解析/对象约束核对实际命中，检查单位、优先级、精确网络覆盖及规则严重性。
5. 独立测试副本构造低于线宽、间距、孔径、孔环、板边等限制的违规对象，确认对应规则确实报错，同时用满足边界的对照对象排除规则误配；每项检查对象UUID、规则ID和报告位置可追溯。测试对象不得进入交付工程。
6. 规则生效证据绑定PCB、工程配置、DRU、叠层、规则输入和工具版本的哈希。任一相关输入改变即失效，重新检查后才进入正式布局/布线。

现状：design_intent.py 实现部分网络类/逐层规则候选编译；design_intent_audit.py 与 routing_policy.py 提供部分核对。它们不等同于全工艺预设器，也没有证明所有关键规则均通过原生违规注入测试。不得用“配置JSON存在”代替“规则已生效”。

## 布局：从物理机理到执行闭环

以下是结合原厂布局原则提出的开发方案，并非行业存在一套可保证任意电路全局最优的算法。布局是离散角度/面别与连续坐标混合的约束问题；最短飞线不能证明真实回流、EMI、热或可布线性合格。

第一层是硬可行域：板内、实体/courtyard不冲突、孔/接口固定、限高、工艺/安全净空、天线禁区和关键原厂约束。第二层才比较性能代理指标：指定焊盘连接距离、关键回路几何、估计拥塞、换层数与热耦合。最后比较对齐和美观。采用分层判优，不允许加权总分抵消硬违规。

| 步骤 | 输入与实际动作 | 验收/失败处理 |
|---|---|---|
| P0 库存和几何 | 真实PCB/网表/封装来源；读取UUID、坐标、角度、面别、焊盘变换、courtyard、板框、禁区及高度 | 每个封装唯一归属模块；不支持几何交人工复核，不猜测 |
| P1 固定结构 | 连接器、孔、开关、外壳/紧固件、公差与装配工具空间 | 对齐机械基准，固定对象回读；修改须显式变更 |
| P2 功能规划 | 按真实拓扑建立模块图，区分噪声源/敏感受体，保留接口和总线通道、完整参考面 | 区域容量和逃线通道可行；区域划分不自动切割地 |
| P3 关键局部 | 电源先按原厂开关状态识别热回路；去耦按电源焊盘到电容再到地返回路径；晶振、ESD、终端、反馈、RF逐项绑定来源 | 不用器件中心距离证明电气合格；各局部保留旋转/移位候选 |
| P4 模块粗放置 | 固定关键局部相对关系，移动模块锚点；评估外部网络与通道 | 无实体重叠；关键约束不退化；报告未能评估的热/SI问题 |
| P5 局部优化 | 枚举允许角度，在合法区域小步移动/交换，确定随机种子与预算；每次先硬检查再比较代理指标 | 无改善或超预算停止并返回最好可行候选；不可行则输出冲突约束 |
| P6 扇出与试布 | 对密集焊盘、窄通道、关键连接做真实后端试布，在独立副本检查连通、过孔及拥塞 | 失败返回P2–P5；飞线长度下降不能代替可布线证据 |
| P7 受控执行 | 单写入者、检查板路径及输入哈希，按小批移动/旋转UUID，回读坐标/角度/面别 | 超时先回读；发生偏差停止，不盲重试；移动不假定自动拖线 |
| P8 保存与复验 | 保存重载、原生DRC、placement_review、局部/全板视觉和适用3D审查 | G3有效后才正式布线；后续移动使受影响布线和审查失效 |

局部优化推荐先实现可解释的候选枚举/局部搜索，再按需求引入模拟退火等启发式；规则化的重复模块可用约束求解器，复杂板不能指望一次求解全部坐标。HPWL仅作普通网络线长代理；拥塞可按网格需求/层容量估计，关键回路面积只有在真实引脚及路径明确时才有意义。无SI/PI/热求解器时只能报告代理指标，不能宣称性能通过。

placement_review.py 继续作为独立只读检查器。建议新增 placement_extract → placement_candidates → placement_optimize → placement_apply → placement_verify，分别负责几何提取、候选生成、优化、真实操作及独立验收；这些是待实现接口，禁止调用为现有工具。每次输出包含 before/after哈希、UUID变更表、硬约束结果、指标差异、工具版本、失败原因与恢复候选。

首批适用范围应限定为经过测试的低速板、已支持的封装面别/轮廓和明确制造参数；旋转/镜像、底层、异形板、锁定件、密集BGA、已布线器件等必须有独立测试再开放。软件夹具、真实KiCad保存重载/故障恢复和实际工程案例是不同证据，不能互相替代。

## 节点10：七步布线

10.1 **规则核验**：核对当前工程身份、规则实际命中、制造能力、布局G3及后端支持范围；缺项阻断。

10.2 **全网分类**：以真实引脚、拓扑、协议、原厂约束建立逐网分类表；普通/电源/高电流/热回路/差分/时钟/等长/敏感模拟/Kelvin/RF/人工处理；未知网络不得默认为普通。检查覆盖、冲突和例外来源。

10.3 **关键网络**：按约束紧迫性和依赖关系排序，专项后端不足则停在该网络；落实参考面、换层、差分耦合、回流及拓扑，保护已验收对象。

10.4 **普通信号**：按通道和层容量执行小批连接、避让与过孔；每批回读铜线、网络及未连接项。A*网格候选不能直接作为真实铜线验收。

10.5 **电源与地**：落实电流/温升/压降与回流约束，执行必要铜线、铜区、缝合/返回过孔和覆铜；检查孤岛、颈缩和连接。不得全局假设GND只靠最终铺铜。

10.6 **优化检查**：核对间距、线宽、孔几何、差分、长度/时延、关键回流、扇出与保护对象；优化不得降低硬规则。任何移动/改层按影响回退复验。

10.7 **保存重载**：绑定同一候选执行覆铜、原生连通与DRC、网络覆盖、规则命中及前后对象差异检查；必要未连接为零，未解决适用阻断项为零，最后进行G4逐层评审。外部路由器SES生成不等于已经回导/保存/复验成功。

## 依据与适用限制

- [KiCad 10 PCB官方手册](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html)：Board Setup、Constraints、Net Classes、Custom Rules和DRC；需使用实际安装版本验证接口与规则支持。
- [ADI混合信号PCB布局指南](https://www.analog.com/en/resources/analog-dialogue/articles/what-are-the-basic-guidelines-for-layout-design-of-mixed-signal-pcbs.html)：功能分区、信号流、去耦和返回路径。此类通用指南不能覆盖具体芯片数据手册，也不把其中的示例距离、层数或主控位置推广为所有板的规则。

开发优先级：完整规则映射及原生生效验证 → 一个限定板型真实布线闭环 → 关键局部布局执行及独立验收 → 原理图几何编辑 → 高速/RF/热等专项。新增规范只约束行为，不增加未经实现与测试的自动化能力。
