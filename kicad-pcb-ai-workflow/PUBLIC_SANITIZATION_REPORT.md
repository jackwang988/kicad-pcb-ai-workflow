# Public Skill Sanitization and Sharing Audit

The public bundle must contain only the reviewed Skill source, portable templates and reference policies. Do not embed original manufacturer PDFs requiring separate permission, NDA/customer design projects, local agent caches, credentials, machine-specific authentication tokens, installed commercial Konnect binaries or private capability approval receipts.

When preparing a distributable archive, review path/hostname, e-mail, user identity and hard-coded local runtime directory traces. Templates must have example-safe values rather than real secrets. File hashes inside a release describe the actual distributed source only and do not constitute hardware certification. The component knowledge cache intentionally lives outside the Skill package so public users cannot access others' private source libraries.

After G1–G4 knowledge-reuse updates, continue to distribute only verified code and documentation; actual private device sources, review packets and project evidence remain under their respective access policies.
