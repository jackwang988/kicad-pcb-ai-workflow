1. 与当前main的所有源码、工作流命令、测试和安装包构建流程逐项对比；不能直接以“33项离线测试通过”取代原有319项回归。
2. 确认Konnect工具动态发现、风险分级、按需测试、验收记录哈希与范围匹配在实际Windows环境可用。
3. 用真实样板验证移动/旋转、丝印、走线、过孔、铜皮、保存重载、ERC/DRC、Gerber/钻孔、BOM/CPL。
4. 对仍然依赖pcbnew的只读接口列出迁移清单，在真正等价之前保留受控兼容或阻断；不能降低G3/G4/制造门禁。
